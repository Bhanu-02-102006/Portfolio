# Images Directory

Place your personal profile pictures, project screenshots, and certificate images in this folder.

Recommended files:
- profile.jpg / profile.png (approx. 400x400px, rounded/square)
- projects/ (e.g. project1.jpg, project2.jpg)
- certificates/ (e.g. java_cert.jpg, aws_cert.jpg)

The HTML/CSS will automatically load standard styles. The current implementation uses elegant vector SVGs and gradient mockups so the website works immediately without requiring custom image assets.
